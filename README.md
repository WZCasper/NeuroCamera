# NeuroCamera

Автоматическая нейрокоррекция изображения с веб-камеры в реальном времени: 15-секундная
автонастройка (баланс белого → экспозиция лица → шумоподавление) и вывод обработанного
потока в виртуальную камеру, которую можно выбрать в Zoom/Teams/Discord/OBS.

## Требования

- **Windows 10/11 (x64)** — WPF и DirectShow API из этого проекта работают только на Windows.
- **.NET 8 SDK** (`dotnet --version` должен показать 8.x) — https://dotnet.microsoft.com/download/dotnet/8.0
- Физическая веб-камера.
- Для вывода в виртуальную камеру: бесплатный драйвер **UnityCapture**
  (см. раздел «Виртуальная камера» ниже). Без него приложение полностью работает —
  живой предпросмотр, автонастройка и т.д. — просто выходной поток не будет виден в
  других приложениях.

## Сборка и запуск

```powershell
cd NeuroCamera
dotnet restore
dotnet build -c Release
dotnet run -c Release
```

Либо откройте `NeuroCamera/NeuroCamera.csproj` в Visual Studio 2022 (17.8+) и запустите
через F5 — там же будет доступен визуальный дизайнер XAML.

Если `dotnet restore`/`dotnet build` выдаст ошибку компиляции — пришлите мне полный текст
ошибки, я найду и исправлю причину.

## Виртуальная камера: как это работает и почему нужен отдельный драйвер

Ни одно чисто управляемое (C#/.NET) приложение не может само зарегистрировать в Windows
новое системное видеоустройство — для этого нужен подписанный DirectShow-фильтр/драйвер,
а это отдельный нативный компонент, устанавливаемый через инсталлятор. Поэтому
`VirtualCamWriter.cs` реализует **клиентскую** сторону протокола общей памяти открытого
проекта **UnityCapture** (github.com/schellingb/UnityCapture, MIT/zlib) — то есть отправляет
кадры уже установленному драйверу. Сама программа не подделывает и не имитирует эту часть:
протокол (общая память + мьютекс + два события) реализован по исходникам `shared.inl` этого
проекта через P/Invoke к kernel32.dll.

Чтобы виртуальная камера реально появилась в списке устройств:

1. Скачайте UnityCapture: https://github.com/schellingb/UnityCapture (кнопка Code → Download ZIP,
   либо `git clone`).
2. В папке `Install/` запустите `Install.bat` **от имени администратора** — это одноразовая
   установка драйвера "Unity Video Capture".
3. Откройте эту камеру в любом приложении-потребителе (Zoom, Teams, OBS, стандартное
   приложение «Камера» Windows) — именно потребитель «активирует» канал общей памяти.
4. Запустите NeuroCamera, выберите физическую камеру, нажмите «Включить поток» —
   в панели «Виртуальная камера» появится «Виртуальная камера подключена», и обработанное
   изображение начнёт идти в «Unity Video Capture».

Если сначала запустить NeuroCamera, а Zoom/Teams/OBS открыть позже — ничего пересоздавать
не нужно: приложение само переподключается каждые 2 секунды.

## Структура проекта

| Файл | Назначение |
|---|---|
| `NeuroCamera.csproj` | Проект .NET 8 WPF, зависимости OpenCvSharp4 |
| `MainWindow.xaml(.cs)` | UI: выбор камеры, кнопка «Автонастройка», предпросмотр, прогресс-бар |
| `ViewModels/MainViewModel.cs` | MVVM-состояние экрана, маршалинг событий на UI-поток |
| `Engine/VideoEngine.cs` | Выделенный поток захвата/обработки/рендера (отдельно от UI-потока) |
| `Engine/CalibrationEngine.cs` | State machine автонастройки на 15 секунд (3 фазы по 5 секунд) |
| `Engine/ImageProcessor.cs` | Вся математика OpenCV: AWB, детекция лица, гамма/контраст, билатеральный фильтр |
| `Engine/VirtualCamWriter.cs` | Клиент протокола общей памяти UnityCapture (P/Invoke) |
| `Interop/DirectShowInterop.cs` | Перечисление имён физических камер через DirectShow COM |
| `Common/MatImageConverter.cs` | Конвертация `Mat` → `BitmapSource` / RGBA-байты |
| `Assets/haarcascade_frontalface_default.xml` | Официальный каскад Хаара из репозитория OpenCV |

## Честно о том, что не проверено

Сборка WPF-приложения требует Windows — у меня в этой среде его нет, поэтому код не
прогонялся через `dotnet build`. Каждый файл написан и вручную перепроверен на соответствие
реальным сигнатурам OpenCvSharp4/WPF/Win32 API, XAML-файлы проверены на корректность XML,
скобки/кавычки — на баланс. Протокол виртуальной камеры сверен построчно с исходным кодом
`shared.inl` проекта UnityCapture. Тем не менее первую сборку стоит сделать самому и прислать
мне текст любых ошибок компиляции — так я смогу поправить всё быстро и точно.
